# Immunitywize

Indian snack storefront built with Next.js, React, TypeScript and Zustand.

## Development

```sh
npm ci
npm run dev
```

## GitHub Pages

The Pages workflow builds and deploys main automatically. Live preview: https://billiondollars2204-creator.github.io/yis2/

This is a design preview: food images and pricing are illustrative. Checkout records demo orders locally and takes no payment. Business details and operating policies need confirmation before real sales.
